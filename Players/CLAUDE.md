# Players — per-character state and input

`CompanionPlayer.cs` is the ModPlayer: the has-companion flag (auto-spawn in `OnEnterWorld`), the health bar position, the bag, the overlay toggle in `ProcessTriggers` (the keybind, default the left square bracket, plus raw bracket / F6 / grave / ISO-section as a fallback, with every newly pressed Oem key named in the log; the key left of 1 turned out to be dropped by FNA on this keyboard, see the root file's traps, and the raw list rather than the default is what makes the overlay reachable at all, because a binding saved by an earlier version outranks the registered default permanently — which is why the overlay was dead for the whole 2026-09-09 session), the right-click on the companion that opens the bag in `PreUpdate`, and a log line on world enter saying whether the companion spawned and how full the bag is. Singleplayer only: the one instance that matters is `Main.LocalPlayer`'s.
