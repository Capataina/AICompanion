# Extensions are activated by an observed limitation of the complete core

The [implementation plan](<../Implement the Retained Course Brain.md>) includes ordinary uncertainty, player interference, random motion, changing intent, weaving, dependency repair and full decision instrumentation. None waits for a module. This folder contains optional later investments whose extra complexity needs a measured reason.

```text
Modules/
├─ CLAUDE.md                              activation rules and the extension map
├─ Compare Several Motion Models.md      distinct movement regimes defeat one useful forecast
├─ Explore Larger Course Reorderings.md   local order repair demonstrably misses better trips
├─ Reuse Demonstrated Interaction Methods.md repeated real protocols justify reusable methods
└─ Sample Uncertain Future Outcomes.md    calibrated stochastic futures change worthwhile choices
```

Every extension replaces or enriches one existing prediction/search contract. The course remains the sole owner of the next action; observation remains the owner of facts; native receipts remain the owner of learning evidence. A module has no production placeholder or default-off feature flag in V1. Read the recorded symptom and matched comparator before implementing one. If its measured benefit disappears, remove its runtime machinery and retain the evidence here.
