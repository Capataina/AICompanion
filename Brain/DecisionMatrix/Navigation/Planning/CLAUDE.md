# Planning — a node is a pose, an edge is a proven move

What a node is, how edges are generated from what the body can do, the search over them, the path it returns and the bounded reachability questions the senses ask. The mechanism at depth (poses, drops lowered row by row, jump profiles simulated, the edge cache and its invalidation box) is in `../CLAUDE.md`; this file is the map and the seams.

```
Planning/
├─ CLAUDE.md
├─ NavGrid.cs        what a node is: a feet tile where BodyPhysics.Stand finds a pose and no lava is in the column; block, support, liquid, submerged-head, lava-count and platform-underfoot tests over the world interface; the open span beside a lip (its columns and its centre) that a drop is planned across and steered along; FeetWorld, which is the pose's own point (off-centre in a tight column, partway down a slope); and the jump box and drop limits
├─ AStar.cs          the search, and Region, a breadth-first flood over the same edges that returns every feet tile reachable within a budget and whether the region ran out before the budget did (the positioner's reachability tier, the replay tool's third line); the edges of a node are whatever the traversals in `../Traversals/` prove out of it, each scaled double from inside liquid; a drop with no way back is offered to a plan only while AllowOneWayDrops is true (the brain: following, guarding, or saving itself), where "no way back" is a bounded return probe run for any fall deeper than Traversal.ClimbReachTiles and memoised separately from the edges because it depends on a whole region's shape; Region takes refuseOneWay and the positioner always passes it, so the region it scores against is the one the body can come home from; arriving with the head under water multiplies the price; each lava tile in a node adds a flat price, and lava nodes exist only while AllowLava is true (the brain sets it from the companion's life each tick); nodes inside Avoid rectangles (reachable enemies set by the brain each tick, and the navigator's own stuck or faulted steps) add a flat price; a search that runs out of budget or region returns a partial path to the closed node nearest the goal; the edges of every tile a search opened are kept between searches (the geometry only, keyed by tile and the lava switch, with the enemy and liquid prices applied on read; a killed or placed tile drops the entries whose scans could have read it, TileChanged, a box a drop deep above it and a jump high below it and EdgeReachX wide; every entry is remade after EdgeCacheLifeTicks for the changes no hook announces; CacheEdges off for the replay's --no-cache); TraceClosed, set only by the replay tool, keeps the closed set for drawing
├─ NavPath.cs        the steps, first first, each with its move kind (walk, jump, drop, fall-through), the tile it leaves from, what realises it (a jump's velocity scale and start speed, a descent's steer line), how many ticks it was proven to take and the mobility state at its landing; whether the path is partial; and NavNode, what the search and the flood are keyed by: a feet tile and the body's mobility state on arriving there, so two states on one tile are two nodes and a move that spends a counter (an air jump, a dash) plans as an ordinary edge without a second search; every counter is zero today, so a node is its tile, and the public seams (Find from a tile to a tile, Region returning tiles, the edge cache's invalidation box) stay in tiles
└─ Reachability.cs   can a walker/flyer get from A to B; bounded searches that answer "yes" when the budget runs out; the walker search forces AllowOneWayDrops on around itself and puts it back, because an enemy takes any drop and the brain's flag is still whatever the last request set when the senses run
```

The seam that matters is the step: a path step carries everything the traversal needs to perform the move it proved (the kind, the tile it leaves from, the profile or the steer line, the ticks it took), so the follower never re-derives a move from the tiles. The search itself knows no move: it asks the traversals for a node's edges and prices what comes back.
