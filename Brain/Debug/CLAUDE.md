# Debug — the overlay

`BrainOverlay.cs` registers the toggle keybind (default F6; the key left of 1 was tried and is dropped by FNA before it becomes a key on a Mac ISO keyboard, see the root file's traps, so the F-row is back and needs Fn on a MacBook unless the F-keys are set to standard) and, when on, draws above the companion: the running action and reflex, danger, horizon and intent, every action's raw and final score, threat and loot counts, the request kind, the chosen spot and its score, the path length and last plan cost, and the chosen weapon. It also draws the path as dots (green walk, orange jump, blue drop, violet fall-through), the chosen spot in magenta, and a label over every threat (class, urgency, ticks to player, shooter flag, `x` when unreachable). Telemetry (AIC-51) will write the same fields to a file.
